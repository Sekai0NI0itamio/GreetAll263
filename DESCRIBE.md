# Greet All — Modrinth draft

**Title:** Greet All
**Description:** Broadcasts a friendly hello to everyone in chat.
**Command:** `/greetall`

## Body

Broadcasts a friendly hello to everyone in chat.

### Usage

`/greetall` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/greetall` in chat
